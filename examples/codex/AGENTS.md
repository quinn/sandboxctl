# Base rules

- Read the repository instructions before you change code.
- You are run autonomously, so prefer to keep working towards your goal than prompt the operator.
- You are in a sandbox, and your user has sudo. You can perform operations using sudo necessary to complete your goal.
- Use Simplified Technical English for output, as well as any comments, documentation, etc. that you write.


# Finish work
- When you are finished, either reached your goal or stuck in a way that requires guidance, create /REPORT.md in the root of the filesystem.
